# Auto Index Barrel

Automatically maintains TypeScript `index.ts` barrel files and rewrites direct imports to use available barrels.

## Features

- Regenerates existing barrel files
- Creates missing barrels for configured folder names
- Updates imports on save
- Updates all imports through a command

## Settings

- `autoIndexBarrel.autoCreateFolderNames`
- `autoIndexBarrel.rewriteImportsOnSave`
